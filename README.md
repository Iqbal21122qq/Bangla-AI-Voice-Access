# Voice Access বাংলা (Bangla AI Voice Access Android App)

একটি আধুনিক অ্যান্ড্রয়েড অ্যাপ্লিকেশন যা সম্পূর্ণ **বাংলা ভাষা** এবং **Gemini 4 Argon (High-Thinking Mode)** এর মাধ্যমে ফোন নিয়ন্ত্রণ করতে পারে। এটি গুগল প্লে-স্টোরের Voice Access অ্যাপের আদলে তৈরি এবং এতে বিশেষ বাংলা ভয়েস অ্যাকশন যোগ করা হয়েছে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

- 🎙️ **বাংলা ভয়েস কমান্ড (Bengali Voice Control)**: প্রমিত বাংলা ও বাংলিশ উভয় ভাষাতেই নির্দেশ দেওয়া যায়।
- 🧠 **Gemini 4 Argon (High-Thinking)**: জটিল ও বহু-ধাপযুক্ত কাজগুলো নিখুঁতভাবে ভেঙে বিশ্লেষণ করে।
- 🔊 **বাংলা কথ্য প্রতিক্রিয়া (Bengali TTS)**: কাজ সম্পন্ন করে অ্যাপটি বাংলায় কথা বলে ফিডব্যাক দেয়।
- 📺 **ইউটিউব ও গান (YouTube & Music)**: 
  - *"YouTube kholo"* -> ইউটিউব খোলে
  - *"Ai gan ta play koro"* বা *"রবীন্দ্রনাথের গান বাজাও"* -> সরাসরি গান খুঁজে চালু করে
- 📸 **স্ক্রিনশট ও হোয়াটসঅ্যাপ শেয়ার**:
  - *"Screen shot naw"* -> সাথে সাথে স্ক্রিনশট গ্রহণ ও সেভ করে
  - *"Screen shot ti WhatsApp e ei nam e friend k pathaw"* -> স্ক্রিনশট স্বয়ংক্রিয়ভাবে হোয়াটসঅ্যাপে বন্ধুর কাছে পাঠায়
- 📞 **ফোন কল (Phone Call)**: *"Phone e call korbe"* বা *"আম্মুকে কল করো"* -> সরাসরি ডায়াল করে
- 🔢 **Voice Access নম্বর গ্রিড মোড**: স্ক্রিনের বোতামগুলোর উপর নম্বর লেবেল (`[১]`, `[২]`, `[৩]`) ভেসে ওঠে, মুখ দিয়ে নম্বর বললেই সেই বাটনে ক্লিক হয়।
- 🛠️ **ডিভাইস কন্ট্রোল**: ফ্ল্যাশলাইট অন/অফ, ভলিউম বাড়ানো/কমানো, ক্যামেরা চালু।

## 🚀 GitHub-এ পুশ করে APK বানানোর সম্পূর্ণ পদ্ধতি (GitHub Actions CI/CD)

এই প্রজেক্টটিতে **GitHub Actions** প্রি-কনফিগার করা আছে। আপনি গিটহাবে কোড পুশ করলেই স্বয়ংক্রিয়ভাবে ক্লাউডে অ্যান্ড্রয়েড **APK ফাইল** তৈরি হয়ে যাবে।

### ধাপ ১: গিটহাবে নতুন রিপোজিটরি তৈরি করুন
1. [GitHub](https://github.com)-এ লগইন করে একটি নতুন রিপোজিটরি (New Repository) তৈরি করুন (যেমন: `bangla-voice-access`)।

### ধাপ ২: কোড গিটহাবে পুশ করুন
আপনার লোকাল কম্পিউটারে টার্মিনাল খুলে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "feat: Bangla Voice Access with Gemini 4 Argon"
git branch -M main
git remote add origin https://github.com/<আপনার_ইউজারনেম>/<রিপোজিটরির_নাম>.git
git push -u origin main
```

*(যদি আপনি AI Studio-এর সেটিংস থেকে "Push to GitHub" অপশন ব্যবহার করেন, তবে এক ক্লিকেই রিপোজিটরিতে কোড পুশ হয়ে যাবে)*

---

### ধাপ ৩: গিটহাব থেকে APK ডাউনলোড করার নিয়ম
1. আপনার GitHub রিপোজিটরিতে যান।
2. উপরে থাকা **"Actions"** ট্যাবে ক্লিক করুন।
3. চলমান বা সম্পন্ন হওয়া **"Build Android APK"** ওয়ার্কফ্লোটিতে ক্লিক করুন।
4. পেজের নিচে **Artifacts** সেকশনে যান।
5. **`VoiceAccess-Bangla-Debug-APK`** ফাইলের উপর ক্লিক করলেই জিপ আকারে সরাসরি ইনস্টলযোগ্য `.apk` ফাইল ডাউনলোড হয়ে যাবে!

---

### 🔑 (ঐচ্ছিক) GitHub Secrets-এ Gemini API Key যুক্ত করার নিয়ম
Gemini 4 Argon-এর ফুল ক্লাউড সুবিধা পেতে:
1. GitHub রিপোজিটরির **Settings** -> **Secrets and variables** -> **Actions**-এ যান।
2. **New repository secret** বাটনে ক্লিক করুন।
3. **Name**: `GEMINI_API_KEY`
4. **Secret**: আপনার জেমিনি এপিআই কি দিন এবং **Add secret** চাপুন।

পরবর্তী পুশের সময় GitHub Actions স্বয়ংক্রিয়ভাবে এই কি যুক্ত করে APK বিল্ড করবে!
